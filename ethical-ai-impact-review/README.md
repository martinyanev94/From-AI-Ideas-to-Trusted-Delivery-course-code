# Ethical AI Impact Review

This lesson adds a portfolio-level blind-spot review. It checks whether each project names the affected groups it must consider, records sufficient evidence, identifies an accountable owner, and keeps its claim within the evidence boundary.

Run the demonstration from the project directory:

```bash
PYTHONPATH=. python src/main.py
```

Run the tests from the repository root:

```bash
python -m unittest ethical-ai-impact-review/tests/test_portfolio_review.py
```

The reviewer is a structural governance aid. It identifies missing records and mismatched claim boundaries; it does not independently prove that supplied evidence is true.
