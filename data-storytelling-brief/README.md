# Data Storytelling Decision Brief

This small Python project turns an analytical finding into a concise decision brief with context, evidence, limitations, a decision, and a recommended action.

## Run the example

From this directory:

```bash
PYTHONPATH=src python src/main.py
```

## Run tests

Install `pytest`, then run:

```bash
python -m pytest
```

The example uses an illustrative historical finding. Replace it with reviewed evidence before using the brief for a real decision.
