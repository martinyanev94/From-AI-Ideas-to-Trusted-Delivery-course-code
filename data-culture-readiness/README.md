# Data culture readiness

This lesson project turns readiness gaps into an ordered action plan with accountable owners, observable evidence, and review dates.

Run the demonstration from the project directory:

```bash
PYTHONPATH=. python src/main.py
```

Run tests with:

```bash
python -m pytest
```

The prioritization rule orders lower readiness scores first, then higher impact, then higher feasibility. Scores are not proof of culture change; the evidence field defines what must be inspected at the review date.
