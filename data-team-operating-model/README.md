# Data team operating model

This standard-library Python prototype integrates role coverage, intake validation, handoffs, and controlled service transitions.

## Run the example

From the repository root:

```bash
python data-team-operating-model/src/main.py
```

## Run tests

```bash
python -m unittest discover -s data-team-operating-model/tests -p 'test_*.py'
```

The prototype demonstrates workflow structure. It does not establish data quality, business value, or production readiness by itself.
